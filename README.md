# Good Gas — Yêu cầu xóa dữ liệu

Trang tĩnh (GitHub Pages) cho ứng dụng Good Gas (Android `com.gas.ga`, iOS `ga.gas.app`):

- `index.html` — Hướng dẫn yêu cầu xóa tài khoản và dữ liệu (dùng làm "URL xóa dữ liệu" trong Google Play Console)

Bật Pages: Settings → Pages → Source: *Deploy from a branch* → Branch `main` / `(root)`.
